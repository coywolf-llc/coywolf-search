Replaces WordPress search with a custom full-text index: BM25 ranking, fuzzy and prefix matching, and instant typeahead.

== Description ==

Coywolf Search replaces the built-in WordPress search with a purpose-built full-text engine.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/coywolf-search/`.
2. Activate it through the Plugins screen.
3. Go to Settings → Search and build your index.

== Frequently Asked Questions ==

= Does it change my theme? =

No. It replaces the results WordPress returns for `/?s=`; your theme's search template renders them.
