# Coywolf Search

> [!IMPORTANT]
> Coywolf Search is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). The plugin is closed in the WordPress.org Plugin Directory. This repository is archived and read-only.

## Use Coywolf Pack instead

Coywolf Search is now the [Search](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/search.md) module in Coywolf Pack. EmDash's built-in full-text search already ranks results with BM25, and the module adds as-you-type results, a search box and rate limiting.

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

Replaced WordPress search with a custom full-text index: BM25 ranking, fuzzy and prefix matching, per-post-type control, and as-you-type results.

## If you still use it

The last release, [v1.4.4](https://github.com/coywolf-llc/coywolf-search/releases/tag/v1.4.4), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
